Agent_smith is everything required from A-Z for creating a docker container on my desktop. The container will allow for openclaw-like agents to run simultaneously within the container. It will be isolated from the file system of the computer that the container is running on, the user will be able to work with repos on github through using SSH or another Github validation method. Files will be pulled down into the container and modified by agents. The agents will not interfere with each other because they will be working independently in a repo, or document. The container will be started with a default argument for number of agents--say 4. There will be a way to spin up more agents and assign more tasks without starting another container. Any task that requires cross-repo modifications is not something the agents in the repo have full and immediate authority to do--this aims to prevent difficulty during human-auditing, to prevent complicated mix-ups between agents, and to keep token burn rate low. In the code, coherence is critical in a way such that it is easy for a human beings to grasp the functionality, edit the code, and use Agent_smith.
